# Soma

Soma is a calmer, human-first social home for art and craft—built to favor care and quality over volume.

## Design source of truth

Read [`design-system/soma/MASTER.md`](design-system/soma/MASTER.md) before designing or changing interface components. It defines Soma's product philosophy, color tokens, typography, spacing, component patterns, and motion rules.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
